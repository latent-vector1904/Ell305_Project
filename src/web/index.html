Cache bench

The three 16-byte read-only caches from the board, driven by the C++ simulator. Type addresses, empty a cache, and compare the hit path.

Direct Two-way LRU

Each cache is 4 lines of 4 bytes in front of a 256-byte memory. The byte at an address is the address itself. A hit costs 2 enable cycles and a miss costs 9, so AMAT = 2 + 7 × miss rate.

Direct-mapped uses tag [7:4], index [3:2], offset [1:0]. Two-way uses tag [7:3], set [2], offset [1:0], fills an empty way first, then the least recently used way. Fully associative uses tag [7:2] and offset [1:0], and any line may hold any block.

This page only displays results. The placement, the byte, and the counts come from cache_bench.
